流程一：实时沟通

  1. 主页「沟通」→ 联系人列表（焦点停在第一个有未读的人，没有未读时停在「当面说话」）。
  2. 选家属 → 通讯方式：「文字消息」或「视频通话」。
  3. 文字消息：用字母块、拼音、字或常用语写好，选右侧「发送」（或预测层末尾的「发送」）→ 消息进入记录，显示“发送中… → 已送达”，对方在线时约 3 秒后回复。
  4. 视频通话：显示“正在呼叫…”→ 接通后计时 → 「挂断」需要确认 → 回到通讯方式，焦点在「视频通话」。对方离线时显示“无人接听”，然后返回。
  5. 当面说话：写好后选「说出」→ 朗读并全屏显示 →「返回修改 / 再说一遍 / 清空」（清空要确认）。
  6. 邀请家属：显示邀请码 →「返回联系人」，焦点回到「邀请家属」。
  7. 来电：任何页面都可能弹出 →「接听 / 拒绝」→ 结束后回到被打断的页面，焦点和没写完的文字都保留。

流程二：生活助手

  1. 主页「生活助手」→ 对话记录、草稿、底部四项、右侧模拟家居。
  2. 「输入」→ 输入界面（顶部标明“问助手”，常用语换成助手指令）→ 选「发送」直接提交；选「返回」时文字留在草稿里，焦点停在底部「发送」。
  3. 发出后显示“正在回复…”，底部暂停操作，不会误触「退出」。
  4. 问答：回复进入对话，焦点回到「输入」。
  5. 点播：“看央视新闻”打开电视并切到 CCTV-13；“播放《演员》”打开音乐。电视菜单和音乐页的返回项写作「返回助手」，回来后焦点在「输入」。
  6. 家居操作：回复里出现「取消 + 候选操作」，取消先亮且第一次多停 1.5 倍时间；焦点移到某个候选时，右侧对应设备显示“旧值 → 新值”。确认后设备行闪绿，三轮都不选按取消处理。
  7. 需要补充：比如“看体育台”有两个台，助手追问时保留原草稿，选「继续输入」接着补充。

以下为 v2 设计说明（仍然有效）

先说结论：一种动作语法、一条动作栏、反馈出现在视线所在处

现有版本功能完整，但同一个动作在不同页面含义不同（字母块页左看＝选中，其余页面左看＝改方向）；界面也没告诉患者此刻每个动作会做什么、刚才的动作有没有被识别、现在能不能做下一个。识别有约 1 秒窗口，命令后要连续 Rest 才解锁，扫描光标却不等人。重构就是把这三件事做进界面。

我们在为谁设计

事实（来自项目）对交互的含义
只有左看、右看、咬牙每页最多 3 种即时意图，靠“扫描 + 确认”扩展。三种动作的含义必须全应用一致。
1 秒窗口、100 ms 步长、3/5 投票，命令后需 3 个合格 Rest 窗才解锁做动作到生效有延迟，光标可能已经换项；连做两次，第二次会被吞。界面要显示“放松 → 就绪”，并补偿延迟。
评分里误触和漏判扣分最重误触一定会发生：破坏性操作要确认且默认取消，删除随时可达，呼叫可撤销，误入的页面一步可退。
横屏 Pad 2560×1600，床旁支架，照护者在旁远距离、卧位、易疲劳：字大、对比高、焦点只用一种颜色；配置与诊断交给照护者。

六条原则

1. 咬牙永远是“就是它”任何页面、任何弹层，咬牙只执行当前高亮项（游戏直接控制除外，动作栏写明）。
2. 左右看永远是空间方向朝哪边看，事情就往哪边发生：选左侧的块、切到右侧、扫描改向左、二选一选右边。
3. 动作栏把规则写在屏幕上底部三格与三个动作的位置一一对应，实时写出此刻的含义。
4. 反馈出现在视线所在处左看左边缘亮，右看右边缘亮，咬牙中心出现脉冲环，动作栏对应格同时闪一下。
5. 为延迟和误触设计停留进度条；换项后 400 ms 内到达的命令按上一项执行；改方向后当前项重新计时；放松三点 0/3 → 3/3 才可再做动作。
6. 只有一种“等待”除了游戏直接控制，凡是有选项的地方，高亮都会自己移动，患者只需等目标亮起再咬牙。确认框也不例外，不再有“需要先左右看选、再咬牙”的特殊页面。

每套只用一种焦点色，全应用只表示“光标在这里”。绿色只表示已确认/就绪，红色只用于呼叫和紧急语。底色不用纯白和纯黑：日间暖瓷白减轻反光，夜间墨蓝黑配暖白文字，压低眩光。

文字对比：日间正文约 15:1，夜间约 14:1；焦点色对底色均 ≥ 4.5:1（珊瑚日间 3.9:1，只用于描边和大字，不用于小字）。

警报与焦点的区分：珊瑚焦点和红色色相接近，所以不单靠颜色区分，而是靠形式区分。全应用只有「呼叫护士」是实心红底白字，其余卡片都是白底或深底；呼叫倒计时是整屏红底。紧急常用语用红色描边、红字和左侧红条。警报红：日间 #C8102E，夜间 #E0243F；焦点珊瑚：日间 #D9502A，夜间 #FF8C5E。

焦点与动效

焦点：2 dp 焦点色描边 + 5 dp 外圈 + 8–12% 底色 + 放大 2.5%；底部 5 dp 停留进度条按扫描方向填充；右上角方向箭头。选中瞬间变绿 450 ms。换项 140 ms；边缘光与脉冲 450 ms；画廊平移 500 ms；切换日夜 300 ms 渐变。开启“减少动画”时取消缩放、脉冲和滑动。

已定决策

珊瑚配色；画廊只用于娱乐页；「说出」接系统朗读；呼叫护士只做本地警报（循环警报音）；照护面板长按 2 秒打开，主页不显示波形；确认框改为两项自动扫描。施工细节与数值见同目录 IMPLEMENTATION_SPEC.md。
