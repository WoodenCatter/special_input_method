# 生活助手第一版联调

## 启动电脑服务

如果电脑还没有安装项目的 Python 依赖，在项目根目录打开 PowerShell，执行以下两行。

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r assistant_server/requirements.txt
```

用记事本打开项目根目录的 `.env`，在等号后填写 DeepSeek Key 和你的连接码。连接码用 6 到 64 个英文字母、数字、下划线或短横线。`.env` 已加入 Git 忽略规则。如果文件不存在，首次双击启动脚本会创建它。

```dotenv
DEEPSEEK_API_KEY=
ASSISTANT_ACCESS_CODE=
```

保存后双击 `start-assistant.cmd`。看到 `Uvicorn running` 后保持窗口打开。以后每次启动只需双击脚本。修改 `.env` 后，按 Ctrl+C 停止电脑服务，再双击启动脚本。

## 连接平板

1. 让电脑和平板连接同一可互访的局域网。用 `ipconfig` 查看电脑 Wi-Fi 网卡的 IPv4 地址。
2. 用 Android Studio 将调试版 Run 到平板，打开「首页 → 生活助手」，触摸右上角的「设置」。
3. 输入电脑地址，例如 `http://192.168.1.10:8765`，再填 `.env` 中设置的**连接码**。
4. 点「测试连接」，看到电脑已连通后点「保存」。测试连接只检查服务可达和 Key 是否已配置。下一步提交日常问答才会真正验证 DeepSeek。
5. 若平板连接失败，确认服务仍在运行、Windows 防火墙允许可信局域网访问 8765 端口，以及 Wi-Fi 没有启用设备隔离。HTTP 联调限调试版，在可信局域网使用。

## 验收用例

| 操作 | 预期 |
| --- | --- |
| 输入「为什么天空是蓝色的」并发送 | 电脑调用 `deepseek-flash`，平板在聊天区显示一问一答。 |
| 输入「看央视新闻」并发送 | 打开现有电视页并选中 CCTV-13。直播加载结果由电视页显示。 |
| 输入「播放《演员》」并发送 | 打开本地音乐页并播放曲库中的指定歌曲。若歌曲已删除，可在音乐页重新导入，或点播其他现有曲目。 |
| 空调开启并处于制冷时，输入「我热」 | 聊天区显示降温和取消。确认降温后，设定温度下降 1°C。 |
| 空调关闭时，输入「我热」 | 聊天区显示打开空调和取消。确认后开启制冷。 |
| 两盏灯都关着时，输入「开灯」 | 聊天区显示打开大灯、打开床头灯、取消三个选项。 |
| 输入「窗帘开到一半」 | 确认后，窗帘开合度显示 50%。 |
| 输入「空调一分钟后关机」 | 空调开启时，确认后显示关机倒计时，到时间后模拟关机。 |
| 输入「看体育台」 | 存在多个匹配项时，显示需要补充的信息。 |

底部依次扫描「输入」「清空输入内容」「发送」「退出」。输入法中的「完成」把文字保留在底部草稿区。「继续输入」会带着同一份草稿重新进入输入法，选中底部「发送」后才提交。开灯、关灯等指令可从输入法的常用语选择。可用悬浮球模拟扫描，或在右侧触摸测试区用键盘编辑同一份草稿。音乐和电视用应用内返回键可回到助手。

模拟家居的当前状态会随请求发送。助手提出设备操作时，光标会转到聊天气泡里的候选和「取消」。咬牙或触摸可以确认当前选项，选完后光标回到底部。更新此功能时，重新安装平板调试版并重启电脑服务。

服务用 `/responses` 的 `json_schema` 请求结构化结果，并校验设备、媒体 ID 和状态。Python 契约测试可以用以下命令运行，测试使用模拟上游，不需要 Key。

```powershell
& .\.venv\Scripts\python.exe -m unittest assistant_server.test_server -v
```
