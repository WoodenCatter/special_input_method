# 第 11.4 节行为验收

使用 Production Debug、API 35 平板模拟器、2560×1600 和 320 dpi。自动轮转观察关闭 `freeze`；需要精确重现某个焦点时使用 debug 广播单步操作。

| 项目 | 操作与观察 |
|---|---|
| 扫描持续性 | 在首页、联系人、通讯方式、邀请、文字消息、助手、娱乐、设置、电视菜单、音乐各观察至少 30 秒，采样动作栏或字母翼，均观察到多次变化。此次抽查发现从沟通页进入当面说话时字母块停在 ABC。已移除离开沟通页时对共享输入器的重复停用，并增加从联系人列表触摸「当面说话」的计时回归。修复后，手动模式下连续观察 32 秒，六个字母翼选项均实际获得过焦点。 |
| 手动扫描与前后台 | 首页右看移到「生活助手」，静候超过两个默认停留周期，焦点保持。打开照护面板并发送右看和咬牙，关闭后焦点仍在「生活助手」。退到 Android 首页时发送咬牙，广播返回 inactive，恢复后仍在同一张卡。 |
| 切换方向与补偿 | JVM ScanCursorTest 检查同向、反向、399/400 ms 补偿边界及确认超时。沟通列表与候选输入器现在在暂停边界清除上一项、恢复向右方向，保留当前项和已输入内容。 |
| 聊天、视频与返回 | 用调试联系人写入「叫医生」，注入妈妈来电，先亮「接听」。拒绝后草稿及动作栏选项与来电前一致。触摸发送收到预设回复；从文字页返回聚焦「文字消息」。调试视频挂断先亮「继续通话」，选挂断后回到「视频通话」。系统返回从候选层先回字母块，再返回通讯方式。 |
| 邀请家属 | 在无服务配置状态通过联系人页进入，出现配置提示；按系统返回后焦点回到「邀请家属」。调试联系人模式关闭冻结后，可生成六位码、换新并返回同一入口。 |
| 生活助手与呼叫护士 | 调试助手输入「我热」，确认先亮「取消」，下一项预览 25°C，确认后设备行显示 25°C。「看央视新闻」打开 CCTV-13，返回助手聚焦「输入」；「看体育台」收到追问，重新进入编辑仍保留原文。首页选「呼叫护士」进入倒计时，左看取消后仍聚焦「呼叫护士」。 |

当面说话选「说出」后默认聚焦「再说一遍」。打开清空弹层后先亮「取消」，六次单步前进后原句仍保留。

本次构建 Production Debug 和 Demo Debug，Production lint 通过。168 项 JVM 测试、27 项模拟器测试、5 项 JS 交互测试、麻将引擎测试以及 5 项助手服务契约测试通过。服务契约测试使用本地上游替身，未验证真实模型回复延迟或直播流。

真实耳机就绪点、识别到界面的端到端延迟、双端在线消息及断网重发去重、生产邀请码兑换、真实视频媒体及拒绝权限流程仍需已绑定的测试账号和相应设备。模拟器的预设回复和通话仅用于验证界面状态迁移。
